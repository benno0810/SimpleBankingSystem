# Simple Banking System

A Python-based banking system that allows users to create accounts, deposit money, withdraw money, and transfer funds between accounts. The system persists data using CSV files.

## Features

- Create new bank accounts with name and initial balance
- Deposit money to accounts
- Withdraw money from accounts (with overdraft protection)
- Transfer money between accounts
- View account statements
- CSV-based persistence for accounts and transactions
- Docker containerization support
